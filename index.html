      A focused learning loop

      ExamPilot is designed around one simple idea: practise with the material you are actually studying, then return to the source to check your understanding.

      01 · Start with your notes

      Paste course material or add supported text-based files. Choose a topic that is covered in the material.

      02 · Practise actively

      Answer in your own words. Change the question style or topic to explore a different angle and reduce unnecessary repeats.

      03 · Return to evidence

      Compare your response with the passage shown. Use it to decide what to revise rather than treating a simple overlap signal as a grade.

      What this preview can—and cannot—do

      • With AI mode off, questions use finite template-and-source combinations and feedback measures word overlap; neither feature is semantic grading.
      • With AI mode on, the secure API requests model-generated questions and concept-level feedback. The model can still make mistakes, so source evidence is validated and should be checked.
      • When AI mode is enabled, the full notes are sent to the ExamPilot API for context selection and selected relevant excerpts plus your answer are sent to the AI provider. Do not submit confidential information.
      • Scanned PDFs need OCR, which is not included. The full local Flask project separately supports Ollama-based AI.
